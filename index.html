「文字を指定」では 全角【】 で囲んだ中の文字が「その種類のランダム文字」になります（数字→数字 / A→大文字 / a→小文字 / 記号→記号）。例: 124【35$A】 → 12412!B のように。【】の外はそのまま使われ、使った文字種は割合(%)に含めて計算されます。【】内を全角の波 〜（または ～）で囲むと、その囲んだ範囲だけ並びがシャッフルされます（範囲外は位置そのまま）。例: 【〜1A〜#】 → A2&（1とAだけシャッフル・記号は必ず末尾）。全角 ＋ で種類をつなぐと「どちらか」になります。例: 【A＋1】 → 大文字か数字を1文字（B や 7）。
パターンで全体を指定（＊＝ランダム）
パスワード全体の並びを1行で指定します。記号の意味：
＊（全角）＝ ランダム埋め。桁数に合わせて長さを自動調整し、完成形が%比率に合うよう中身を配分。複数あれば残り桁を均等割り、無ければ末尾に自動で追加。
そのままの文字＝ リテラル（固定。例 Brr23 はそのまま）。
【 】＝ 中は種類トークン → その種類のランダム1文字（数字→数字 / A→大文字 / a→小文字 / 記号→記号）。
〜（全角・【】内）＝ ペアで囲んだ範囲の並びをシャッフル（囲みの外は位置そのまま。1個だけなら末尾までシャッフル）。
＋（全角・【】内）＝ つないだ種類のどちらかを1文字（例 【A＋1】＝大文字か数字）。
例：＊Brr23＊＝前後ランダム＋中央 Brr23／Aa＊【〜1A〜#】＝先頭Aa＋ランダム＋（数字と大文字をシャッフル）＋末尾記号。
・使った文字種は割合(%)に含めて計算されます。・マスク使用中は上の「始める／終わる」指定より優先されます。・半角の * + ~ は通常の記号として使われ、特殊扱いは全角のみです。
